# EXP-001 RSI reversal + MACD confirmation — hold (2026-11-14)

Selected: first `queued` item in registry order. No performance result is claimed.

## What was inspected
- `run_cost_adjusted_backtest.py`, `modules/backtest.py`, `modules/backtest_costs.py`
- `data/cost_adjusted_backtest_latest.json` (generated 2026-08-24, data cutoff ~that date)
- `research/results/price_series.json`, `data/usdjpy_daily.csv`, `data/fred_cache/`

## Missing prerequisites
1. **Not rolling.** The backtest uses one static split (IS 70% / OOS last 30%) over a 180-day
   lookback. CLAUDE.md requires cost-inclusive *rolling* OOS.
2. **OOS sample far too small.** 117 OOS trades across 22 pairs (125 IS); per pair
   typically 4-8. The registry's own diagnosis estimated n≈1,900 trades needed for significance.
3. **Entry rule is not pluggable.** `run_backtest()` is the production TA/FA scoring engine
   (simplified). Testing EXP-001's fixed RSI/MACD rule would need changes to `modules/`
   (forbidden) or a new engine in `research/`, which would be an unvalidated re-implementation
   of the baseline, so "improves the baseline" could not be established on a like-for-like basis.
4. **Data limits.** Price source is Frankfurter daily closes (no OHLC, no intraday, no bid/ask);
   stop/take-profit path simulation and spread are modelled, not observed. `price_series.json`
   covers only ~2026-05-20 onward (hourly snapshots from git history). Long-history daily data
   (FRED, `usdjpy_daily.csv`) exists for G10/USDJPY only, not for the ~22-pair production universe.
5. **Multiple testing.** The existing Reality Check gives p=0.279 for the best pair
   (AUDCHF, n_days=76); the registry already counts 33+ variants tested. No adjustment
   budget has been pre-registered for EXP-001.
6. **Stale.** The cached backtest is ~3 months old.

## What would unblock it
- A multi-year daily (ideally OHLC) history for the production pairs, stored under `research/`.
- A research-local baseline engine reproducing current entries, with a walk-forward rolling
  (e.g. expanding IS, fixed OOS windows) harness in R-multiples, 3 cost scenarios
  (conservative/standard/adverse spread+slippage), and a pre-registered multiple-testing rule.

Existing informal checks (2026-08-26, in the registry) remain non-evidence.

**status: hold**
